# Yuer Search — Google CSE 精选站点池（2026-11-15）
#
# 背景：Google 已对新引擎弃用「Search the entire web」（JSON API 2027-01-01 停服的同一产品线收缩），
#       新建引擎只能走站点白名单（上限 50 个 distinct domains，本表 ~40 个，留有余量）。
# 用法：PSE 控制台 → Setup → Sites to search（或你看到的 Add sites to include 文本框）→ 每行一条粘贴。
# 语义：*.example.com = 整个域名含子域名；xxx.com/* = 该主机全部路径。超过 50 个需删减后再加。
#
